# student-grade-calculator

## Description
The Student Grade Calculator is a Python program that assigns grades to students based on their marks using predefined grading conditions.

## Objective
The objective of this project is to practice conditional statements such as if, elif, and else and apply them to a simple data analysis problem.

## Grading Logic
| Marks | Grade |
|-------|-------|
| 90-100 | A+ |
| 80-89 | A |
| 70-79 | B |
| 60-69 | C |
| 50-59 | D |
| Below 50 | F |
Marks below 0 or above 100 are considered invalid.

## Technologies Used
Python and  Jupyter Notebook

## Features
1.Calculates grades automatically
2.Handles multiple students
3.Validates marks
4.Displays student marks and grades
5.Uses conditional statements
